# 15-Day Python Internship Challenge

Text of `SmartHireAI_15_Day_Internship_Template.docx`, as supplied by the company.

**Project:** SmartHireAI – AI-Powered Resource Hiring & Workforce Matching Platform
**Duration:** 15 Days
**Target Audience:** Python Interns / Final Year Students

## Project Objective

Build a web application that helps companies match project requirements with the best candidates/resources using Python, Django, PostgreSQL and basic AI-based skill matching.

## Business Problem

Organizations spend significant effort screening resumes and identifying suitable resources. The platform automates candidate registration, project requirement creation, skill matching, ranking, and reporting.

## Technology Stack

Python, Django, Django REST Framework, PostgreSQL/SQLite, HTML/CSS/Bootstrap, Git, Pandas, Scikit-Learn (optional).

## Core Modules

1. User Authentication
2. Candidate Management
3. Project Requirement Management
4. Skill Matching Engine
5. Candidate Ranking
6. Dashboard & Reports

## 15-Day Execution Plan

Day 1: Requirement Analysis & Environment Setup. Day 2: Database Design (ER Diagram). Day 3: Django Project Setup. Day 4: Authentication Module. Day 5: Candidate Profile Module. Day 6: Resume Upload Module. Day 7: Project Requirement Module. Day 8: Skill Mapping Logic. Day 9: Candidate Matching Algorithm. Day 10: Ranking Engine. Day 11: Dashboard Development. Day 12: Reports & Analytics. Day 13: Testing & Bug Fixing. Day 14: Documentation. Day 15: Final Demo & Presentation.

## Deliverables

Source Code, Database Schema, API Documentation, Test Cases, User Manual, Final Presentation.

## Evaluation Criteria

Code Quality (25%), Functionality (30%), UI/UX (15%), Innovation (15%), Documentation (15%).

## Bonus Features

Resume Parsing, AI Skill Extraction, Interview Scheduler, Email Notifications, Resource Utilization Dashboard.
